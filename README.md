# 倫理法人会 単会会員管理システム

倫理法人会の単会向け会員管理Webシステムです。
Googleスプレッドシートをデータベースとして使用し、Cloud Runで動作します。

## 主な機能

### 会員名簿管理
- 会員情報のCRUD（登録・閲覧・編集・削除）
- 氏名・ふりがな・会社名・メールアドレス・追加列による横断検索
- 入会ステータス、カスタムフィールド、追加列によるフィルタリング
- 全列でのソート（氏名・会社名・ステータス・カスタムフィールド・追加列）
- 入会ステータスとカスタムフィールドのインライン編集（一覧画面上で直接変更）
- ふりがな自動正規化（カタカナ→ひらがな変換、日本語名のスペース除去）

### カスタムフィールド・追加列
- **カスタムフィールド**: 単会固有の選択肢フィールド（ドロップダウン）を設定画面から動的追加
- **追加列**: スプレッドシートに自由に列を追加すると、自動検出されて画面に反映

### イベント管理
- イベントの作成・編集・削除（名前・日時・種類・場所・説明）
- 出席者の個別登録・一括登録（検索・全選択対応）
- 出席状態の管理（事前登録・出席・欠席・遅刻）
- 種類別の参加率集計
- 当日チェックモード（会場での出席確認用、ワンタップ切り替え）

### Googleフォーム連携
- Googleフォームの回答スプレッドシートと連携
- フォーム回答からの出席者自動マッチング・一括登録
- 未登録者の新規会員追加
- フィールドマッピングによる会員情報の差分更新
- 重複回答の検出（どちらを採用するか選択可能）
- プレビュー画面での確認後に実行

### CSVインポート
- CSVファイルから会員名簿への一括インポート
- 列マッピング（CSV列 → 会員名簿列、自動推測つき）
- 値マッピング（入会ステータス・カスタムフィールドの選択肢への変換）
- 既存会員との照合・差分検出・重複検出
- プレビュー画面での確認後に実行

### イベント参加履歴
- 会員一覧画面でイベント参加履歴を表示
- 期間指定（3ヶ月〜全期間）での絞り込み
- 出席状態による絞り込み
- 会員ごとの参加回数表示

### ダッシュボード
- 登録済・見込み・お声がけ中の人数をリアルタイム表示
- ステータス別の会員数内訳
- 直近イベントの参加率
- 種類別イベント統計

### ユーザー管理・認証
- Google OAuth 2.0認証
- ロールベースアクセス制御（オーナー / メンバー）
- スプレッドシート共有権限の自動管理

### その他
- レスポンシブデザイン（スマートフォン対応）
- システム内利用マニュアル

## 技術スタック

| レイヤー | 技術 |
|----------|------|
| Frontend | React 18 + Vite + React Router v6 |
| Backend | Express.js (Node.js 20) |
| Database | Google Sheets API v4 |
| Auth | Google OAuth 2.0 + JWT |
| Infra | Google Cloud Run (Docker) |
| CI/CD | GitHub Actions |
| Security | Helmet.js, Rate Limiting, httpOnly Cookie |

## クイックスタート

```bash
# 1. 依存パッケージのインストール
npm run install:all

# 2. GCP初期セットアップ（対話形式）
npm run deploy:init

# 3. Cloud Runにデプロイ
npm run deploy:cloudrun
```

詳細な手順は[技術マニュアル](docs/TECHNICAL_MANUAL.md)を参照してください。
